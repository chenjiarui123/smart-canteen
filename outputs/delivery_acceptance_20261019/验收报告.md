验收日期：2026-10-19（Asia/Shanghai）

**结论：自动化测试、冻结推理、数据完整性及隔离副本中的业务闭环通过；真实浏览器操作和全新环境安装尚未完成，因此暂不签署“完整交付验收通过”。** 本轮没有启动训练、搜索参数或修改冻结模型。

## 环境是否需要安装

本机已经有可用的 Python 3.12.14、后端依赖、Node.js 和前端依赖，已直接完成以下验证，没有新增全局软件。普通 CPU 即可运行，不需要 GPU、CUDA、深度学习训练环境、Docker 或独立数据库服务。

- 当前可用解释器：项目根目录 `.targeted-venv/bin/python`。系统默认 `python3` 为 3.9.6，不应直接用于本项目。
- 项目根目录新增 **`本机验收启动.command`**，双击可复用已验证环境，默认打开 `http://127.0.0.1:8000/`。已验证脚本参数入口；用户已确认手动启动，代理仍无法读取实际页面。
- `smart_canteen_web/.venv` 是旧设备遗留环境，路径与版本不适用；启动入口直接使用可用环境。
- 换新电脑时，推荐安装 Python 3.12 和普通浏览器，再安装 `backend/requirements.txt`。若交付包包含本次生成的 `frontend/dist`，运行时不需要 Node.js；仅重新构建前端时需要 Node.js 22.12+ 的 LTS 分支及 npm。

当前验证环境与 requirements 的三项版本存在差异：

| 依赖 | 当前验证版本 | requirements 锁定版本 |
| --- | --- | --- |
| NumPy | 2.3.5 | 2.0.2 |
| pandas | 2.2.3 | 2.3.3 |
| Pydantic | 2.14.0 | 2.11.7 |

其余列出的 Web 直接依赖与 requirements 一致。当前环境通过不代表锁定版本在全新设备上也已复现。本轮曾尝试建立独立环境并下载锁定依赖，但联网安装的自动审批失败、动作未执行；本轮新建且未完成安装的根 `.venv` 已清理，原有环境未修改。

## 本轮修复

发现 Markdown 将克计价菜的内部数量直接标为“克”，而页面及 CSV 已按 50 克份换算，造成 50 倍差异。已修复 Web `report_generator.py`：

- 推荐表格与低频原始试餐建议均正确换算为克，和 CSV 一致。
- 按售卖单位分别汇总实际备餐量；克、份、个等不再作为一个实际总量混加。
- 原有混合总量标明“模型参考值”；明确高频预测与低频试餐估计的区别。
- 不改变模型、内部 `pred_qty`、销售额或历史存储口径。

新增 2 项有意义的回归测试，验证报告/CSV 一致、输入与历史不变；48 项后端全套通过，真实数据 6 个菜单的导出复核也通过。另提供本机启动入口，并修正根 README 对历史研究失败文件数的说明。

## 性能和业务限制

单个真实数据场景约 2.79～5.75 秒。10 次重复平均 **5.21 秒**、最大 **5.30 秒**；4 路并发平均每请求 **24.86 秒**、总耗时 **25.29 秒**。本次属于短时、少量并发的稳定性验证，不是高并发或长时间压力认证。

1. 销售、天气和校历均截止 **2026-06-10**，距验收日 **131 天**。当前链路可用不等于当前业务预测精度已验证；投入当前日期使用前应补充真实销售及目标天气/校历，这属于数据更新，不是重新训练。
2. 10 道菜存在历史单位变化。SDK 默认 strict 模式会拒绝这些数据；复现旧系统需使用已有的 `legacy_compatibility`，业务清洗需要真实单位依据。
3. Web 可选的“按总需求重新分配”仍沿用混合单位的模型预算，不能解释为物理重量守恒。本轮真实数据闭环使用默认关闭模式；报告已注明参考口径，未升级这一业务算法。
4. 当前仅验证 macOS arm64 的上述环境。前端大包与依赖弃用提示不阻断构建，但不构成性能优化或跨平台认证。
5. 研究套件历史记录为 76 通过、9 失败，本轮没有重跑研究实验。审计确认失配为 demand 的 2 个文件影响 4 项测试、phase 的 1 个文件影响 5 项测试；交付推理不读取这些历史研究注册文件。未修改旧哈希以制造通过。
6. SDK 随包完整性通过；原项目出处快照现为 16/18 匹配，两处差异为 Web 的 UTF-8 读取兼容修复及本轮报告展示修复。SDK 已测试的计算接口不提供 Markdown 导出，本轮没有重新封装或发布 SDK。外层 `sdk.zip` 含旧 SQLite 与开发残留；应使用已检查的 `sdk/dist/smart-canteen-sdk-0.1.0-delivery.zip`。
