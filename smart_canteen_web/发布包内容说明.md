# 发布包内容说明

生成日期：2026-09-18

本发布包用于在新的 Windows、macOS 或 Linux 设备上部署当前智慧食堂网页系统，包含：

- Vue 网页源码及已构建的 `frontend/dist`；
- FastAPI 后端及接口；
- 当前冻结策略模型和参数；
- A／湖畔、F／基础园两套历史销售数据与菜品库；
- 天气、校历及网页选项数据；
- 当前正式推荐历史和已保存推荐菜单；
- 数据更新、备份恢复脚本及测试代码；
- Windows、macOS、Linux 启动脚本。

发布包未包含以下本机生成内容：

- `.venv`：与当前电脑和 Python 版本绑定，由新设备首次运行时重新创建；
- `frontend/node_modules`：包含当前 macOS 平台依赖，且日常运行不需要；
- `data/staging`：尚未确认写入的临时上传文件；
- `data/.locks`：运行时文件锁；
- `data/backups` 中的历史自动备份；
- Python、前端测试缓存和 macOS 元数据文件。

系统当前有效数据、推荐历史和已保存菜单不受上述排除项影响。新设备运行后会自动创建暂存、锁和备份目录。

当前策略为 `targeted_repeat_holiday_20260911`，保留 Trial 18 基础模型及其参数。发布包包含实际业务数据，请按内部项目资料保存。

Python 与依赖安装包未内置。新设备需安装 Python 3.10–3.12，首次启动联网安装依赖；前端已构建，日常使用无需 Node.js。本次另行生成的一周21份 CSV 和独立 SDK 不包含在网页项目包内。
