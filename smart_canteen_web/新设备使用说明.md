# 智慧食堂系统新设备使用说明

本发布包包含网页前端、后端、策略模型、两套餐厅历史数据、菜品库、天气与校历数据，以及当前推荐历史。项目使用相对路径，可复制到 Windows、macOS 或 Linux 设备运行。

## 使用前准备

- 安装 Python 3.10～3.12，推荐 Python 3.12。
- 首次运行需要连接网络，以安装 Python 运行组件；以后启动可离线使用。
- 日常使用不需要安装 Node.js，发布包已包含构建完成的网页文件。
- 请先完整解压 ZIP，不要直接在压缩包预览窗口中运行。

## Windows

双击 `start_windows.bat`。首次启动会在当前目录创建 `.venv` 并安装依赖，完成后浏览器会自动打开：

`http://127.0.0.1:8000/`

如果 Windows 阻止脚本运行，可打开命令提示符，进入项目目录后执行：

```bat
start_windows.bat
```

## macOS

首次运行时，在终端进入项目目录并执行：

```bash
chmod +x start_macos.command
./start_macos.command
```

以后可以直接双击 `start_macos.command`。若系统提示文件来自未知开发者，可在“系统设置 → 隐私与安全性”中允许打开。

## Linux

```bash
chmod +x start_linux.sh
./start_linux.sh
```

## 停止系统

回到启动窗口，按 `Ctrl + C`。关闭浏览器标签页不会自动停止后台程序。

## 数据位置

- 餐厅历史与菜品库：`data/datasets/`
- 天气与校历：`data/features/`
- 网页新增销售数据：各数据集目录下的 `runtime_actual_sales.csv`
- 正式推荐历史：各数据集目录下的 `recommendation_history.csv`
- 已保存菜单与说明：`temp_recommendations/`
- 更新前自动备份：`data/backups/`

复制整个项目目录即可迁移当前业务状态。运行期间不要直接移动目录，也不要同时在多个设备修改同一份文件后再相互覆盖。

## 常见问题

### 端口 8000 已被占用

在项目目录执行：

```bash
.venv/bin/python run_app.py --port 8080
```

Windows 对应命令：

```bat
.venv\Scripts\python.exe run_app.py --port 8080
```

### 首次安装失败

确认设备可以访问 Python 软件源，并重新运行启动脚本。如果单位网络限制外网访问，需要由技术人员提前准备与设备系统、处理器架构和 Python 版本匹配的离线依赖包。

### 页面提示前端文件不存在

确认 `frontend/dist/index.html` 存在。发布包已经包含该目录，不应删除。

### 数据更新前的建议

更新前建议复制整个项目目录作为快照。系统也会在 `data/backups/` 中保存自动备份。
